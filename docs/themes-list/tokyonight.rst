.. _tokyonight:

Tokyonight Theme
================

Based on bash-it's Easy theme, this preset replicates the look of `Tokyo Night Preset <https://starship.rs/presets/tokyo-night>`_ for `Starship <https://starship.rs/>`_.

Prerequisites
-------------

- A `Nerd Font <https://www.nerdfonts.com/>`_ installed and enabled in your terminal.
- A terminal that supports True Color.

Usage
-----

Add the following statements to your `~/.bashrc`

.. code-block:: bash

  export BASH_IT_THEME='tokyonight'

Reload your shell

.. code-block:: bash

   . ~/.bashrc
